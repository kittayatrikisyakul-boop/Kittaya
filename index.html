Reference Zone Alerts

Reference alerts use new daily quotes crossing fixed, manually supplied zones. These are not live SMC confirmations. Gold and oil alerts require a connected price feed. Toggle Popup for desktop notifications and Sound for audio alerts.

How to Set Up TradingView Alerts

1. Order Block Alerts
Right-click on chart at OB zone → Add Alert → Condition: "Crossing" → Set price at OB boundary

2. FVG Fill Alerts
Set alert at FVG midpoint → When price fills the gap, you get notified for potential entry

3. BOS/CHoCH Alerts
Set alert above swing high (for BSL) or below swing low (for SSL) → Confirms structure break

4. Liquidity Sweep Alerts
Set alert just beyond equal highs/lows → When swept, watch for reversal pattern

Pro Tip: Use the "Smart Money Concepts" indicator by LuxAlgo on TradingView for automatic OB, FVG, BOS, CHoCH detection with built-in alerts.
